Labeling guide

Outline all visible planes and targets, even if only one is being followed. Label the visible part of an object at the image edge. Use consistent tight boxes; do not include a long flight path or the whole background. Confirm no objects only when neither class is visible. Predictions are preview only and never become labels automatically.

03 / Train on this computer

YOLOv8 learns 0: plane and 1: target. Only reviewed images enter the dataset. Each run saves a fixed dataset snapshot.

Record at 1080p50. Current flight inference uses full-frame 640. Native-crop inference requires retraining and validation at that scale. Full-frame training at larger input sizes remains available. Compare models on held-out distant-plane flights before deployment.

Native crops preserve distant-plane pixels. All crops retain the source session split; original annotations are unchanged. Adaptive flight detection requires a 640 input HEF trained and validated on native crops; the existing weights currently use full-frame mode.

Hailo uses the selected detector input size and requires the running pi-vision-hailo-compiler Docker container. Compilation preserves best.pt; it does not deploy or activate the model.

Ready

The first run downloads pretrained weights. Start with YOLOv8s at 640 and full frames to match current flight inference. Native crops are an optional retraining experiment. YOLOv8m is available for comparison; training does not deploy the model. Stopping retains completed checkpoints; partial work in the current epoch can be lost.

04 / Inspect plane → target tracking

Test the trained detector on a library image or the live camera. Native tiles inspect the entire image and merge duplicate boxes; its displayed time covers all tiles, unlike the Pi's moving-crop tracking time. This view measures image positions; it does not send aircraft commands or confirm a physical pass.

Standard YOLO runs on the laptop. Selecting a model does not activate it on the Pi.

Train first, then inspect missed objects and false detections on held-out footage. Add corrections to a new training session and train again.

A fixed ground camera cannot infer depth or a balloon strike from two overlapping boxes. The current aircraft exposes throttle and roll; use the Pi remote's Autonomous page for supervised launch and horizontal steering after camera/flight calibration.
